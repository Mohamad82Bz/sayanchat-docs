# API Overview

SayanChat exposes a Java API and Bukkit events for plugin developers.

## Packages

- `org.sayandev.sayanchat.api`
- `org.sayandev.sayanchat.api.event`

## Highlights

- Chat box switching and default chat box
- Chat history and node retrieval
- Session token utilities (web integration)
- Events for messages, mentions, and chat box interactions

See:

- `api/chatbox-api.md`
- `api/node-api.md`
- `api/events.md`
